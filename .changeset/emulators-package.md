'@yolk-sdk/emulators': patch
---

Add the experimental `@yolk-sdk/emulators` package (explicit subpaths only, no root export; runtime dependencies are `effect` and, for the stateful subpaths added in this release, the pinned `@emulators/core`; it never imports other `@yolk-sdk/*` packages). `./router` routes an Effect `HttpClient` to emulators by swapping layers: `EmulatedHttpClient.layer` rewrites routed origins to loopback emulator processes over the host's own client, and `InProcessHttpClient.layer` calls emulator fetch handlers directly. Both keep path and query, fail closed on unknown origins with an error naming only the origin, validate routes when built (loopback-only base URLs for the emulated client), and refuse to build when `NODE_ENV` is `production` or unreadable; the emulated client routes at the send step (so redirect follow-ups and host `mapRequest` changes are routed or fail closed) and sends with `redirect: 'manual'` over `FetchHttpClient`. `./gateway` adds `makeGatewayEmulator`, a plain fetch-handler emulator of the Vercel AI Gateway OpenAI-compatible `POST /v1/chat/completions` endpoint (streamed and JSON completions, DeepSeek-style reasoning, schema-synthesized tool calls, the error envelope, scripted turns, status / mid-stream / truncation faults that never redirect or send bodyless statuses, a credential-free request ledger, and an `/_emulate/*` control plane), plus `gatewayEmulatorRoutes`, its route evidence manifest linked to the Gateway conformance case ids; responses from unverified routes carry `x-emulator-evidence: unverified`. `./node` serves a fetch handler on `127.0.0.1` only (`serveFetchHandler` as a scoped Effect resource, `startFetchHandlerServer` as a Promise) and flushes streamed bodies chunk by chunk.
