'@yolk-sdk/agent': minor

The `@yolk-sdk/emulators/openai` emulator now emulates OpenAI reasoning models as the Chat Completions docs describe them. `reasoningModels` (new option, default `openAiEmulatorDefaultReasoningModels`: `gpt-6-luna`, also added to `openAiEmulatorDefaultModels`) reason unless `reasoning_effort` is `none`, send no reasoning text, and report `usage.completion_tokens_details.reasoning_tokens` (0 for `none`), counted in `completion_tokens`; `/_emulate/state` lists them. A reasoning model answers `max_tokens`, `temperature`, `top_p`, `logprobs`, or `top_logprobs`, and any other model answers `reasoning_effort`, with 400 `{ error: { message, type: 'invalid_request_error', param, code: 'unsupported_parameter' } }` (after model validation, never for a scripted turn, using up no fault; recorded as the ledger's new `unsupportedParameter`). Sending `reasoning_effort` to a model that does not reason was answered 200 before. Models that do not reason keep their wire unchanged, and the Gateway emulator is unchanged. Scripted turns still reject reasoning text fields; script reasoning as `usage.reasoningTokens`.

`@yolk-sdk/agent/providers/openai/conformance` adds three `read` cases for a reasoning model, with synthetic fixtures whose notes cite the OpenAI docs: `openAiChatReasoningEffortCase` (`openai.chat.stream.reasoning-effort`) and `openAiChatJsonReasoningUsageCase` (`openai.chat.json.reasoning-usage`) send `reasoning_effort` and require no reasoning text and a usage report counting reasoning tokens, and `openAiChatUnsupportedParameterCase` (`openai.chat.stream.unsupported-parameter`) sends `max_tokens` and requires a non-retryable 400 with provider code `unsupported_parameter`. `OpenAiConformanceModels` gains a required `reasoning` model id (default `gpt-6-luna`) and `OpenAiConformanceSettings` the required `reasoningMaxCompletionTokens` and `reasoningEffort`; hosts that build these settings must add them, so `@yolk-sdk/agent` takes a minor bump (`@yolk-sdk/emulators` only gains an optional option and stays a patch). `pnpm conformance:openai` takes `--reasoning-model`, `--reasoning-max-tokens`, and `--reasoning-effort`.
