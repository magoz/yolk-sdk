Add the experimental, Node-only `@yolk-sdk/emulators/microsoft` subpath: `makeMicrosoftEmulator`, a stateful Microsoft Graph emulator on the pinned `@emulators/core` custom runtime (loaded lazily). It serves only the Graph v1.0 routes the Microsoft conformance cases use (calendar view with overlap filtering, event create/get/update/delete/cancel, folder message paging with an opaque `@odata.nextLink`, draft create/update/move with immutable ids, attachment listing and retrieval, `$batch` permanent delete, and OneDrive item read, children listing, folder create, delete, and copy) plus the OneDrive copy monitor URL on a SharePoint origin, seeded by default with the synthetic Microsoft fixture entities so the Microsoft conformance cases run unmodified. Concurrent writes to one message follow a deterministic first-arrival-wins rule (409 `ErrorIrresolvableConflict` for the loser). Everything else fails closed with the Graph error envelope. It adds status faults, a credential-free ledger, an `/_emulate/*` control plane, test-only drill knobs, and `microsoftEmulatorRoutes`, its route evidence manifest linked to the Microsoft conformance case ids (all routes unverified).
