Add host instructions and the code mode catalog as an instruction (ADR 0007). `RunInstruction` (`{ key, state, render }`) and `RunConfig.instructions` keep an instruction current in the conversation: before each model request the loop appends a user-role instruction message (a `UserMessage` with the non-model-visible `instruction: { key, state }` envelope) only when its state changed, never rewriting earlier messages, so a changing instruction never invalidates the cached request prefix. Durable hosts driving `runModelTurn` append and persist `instructionMessages(transcript, instructions)` themselves. Nested-access registrations contribute through `instruct`, collected in `ResolvedToolSet.instructions`. `makeCodeModeTool({ catalog: 'instructions' })` keeps the `codemode` description invariant and delivers the catalog (every namespace with its tool count and description, listed tools within the inline budget) as such an instruction, rendered in full, as a short delta, or as a replacement. `ToolDiscovery` gains `pinned`: always listed, outside the inline budget. The React chat projection (`buildAgentChatMessages`, `appendProtocolMessage`) never shows instruction messages as user messages. Hosts that cannot append messages to their persisted conversation may render an instruction's first render into their system prompt instead.
