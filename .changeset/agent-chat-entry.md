New `@yolk-sdk/agent/chat` subpath: the chat projection without React (messages, items, the event fold, the chat reducer, actions, session events), for hosts on another UI framework or folding on a server. `@yolk-sdk/agent/react` re-exports it whole and adds `useAgentChat`, so its imports keep working.

- An event's cost no longer grows with the chat: the projection reads and replaces only the event's turn, and every message an event did not change keeps its reference (a list keyed by message id redraws only what changed). `pnpm bench:chat` measures it: about 15 µs per event after an 8,000-row history, where it was about 600 µs.
- Breaking: `seenEventIds` on `AgentChatEventProjectionState` and `AgentChatState` is now an Effect `HashSet<string>`, not an array (a replay check and an insert cost the same however long the stream ran). Build states with `makeAgentChatEventProjectionState` or `initialAgentChatState`; read it with `HashSet.has` or `[...state.seenEventIds]`; a host that cleared it to `[]` uses `HashSet.empty()`. The client's `AgentClientState.seenEventIds` is unchanged.
- `stepAgentChatProjectionAll(state, events, options)` folds a batch of events as `stepAgentChatProjection` does one: it returns the `projection`, the `statusEvents` to fold into the run's status (each event's `missedStart`, then its `statusEvent`) and `messageIdsChanged` (whether the chat's message ids, in order, changed).
- The projection's state has Effect Schemas, and its types are derived from them: `ChatPartStateSchema`, `ChatToolStateSchema`, `AgentChatPartSchema`, `AgentChatMessageSchema`, `AgentChatExecutionOutputSchema`, `AgentChatExecutionsSchema`, `AgentChatTurnStartSchema`, `AgentChatEventProjectionStateSchema` and `AgentChatStateSchema` on `@yolk-sdk/agent/chat`, and the generic `AgentExecutionsSchema(output)` on `@yolk-sdk/agent/client` (also re-exported from `/chat` with `HitlPauses`). `Schema.toCodecJson(schema)` is a JSON form (`seenEventIds` as an array of ids, options as `{ _tag, value }`); a decoded state continues the fold as the original does. `AgentChatPart`, `ChatToolState` and `AgentChatExecutionOutput` stay `Data.taggedEnum` constructors.
