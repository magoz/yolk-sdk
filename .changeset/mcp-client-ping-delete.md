The local stdio MCP client (`listLocalMcpServerTools`, `callLocalMcpServerTool`) no longer treats a server's own messages as a broken session (#386). Each stdout line is read as one JSON-RPC message (MCP `2025-11-25` basic/transports, stdio): a server `ping` is answered `{"jsonrpc":"2.0","id":<id>,"result":{}}` on stdin (basic/utilities/ping), any other server request gets JSON-RPC error `-32601` (the client declares no client capability), and notifications such as `notifications/message` are ignored. A line that is not a JSON-RPC message still fails the operation. Listings now run in the same session as calls, so the client keeps the server's stdin open until it has its answers. Behaviour change: a server that only answers after stdin closes now fails listings (it already failed calls).

The remote client ends a legacy-era session when it closes (#381): after each operation on a `2025-11-25` connection that holds an `MCP-Session-Id`, it sends `DELETE` with it (basic/transports, "Session Management" item 5) through the SDK's `terminateSession()`. The `DELETE` is awaited, so every legacy operation that holds a session takes one more round trip before it returns (at most 2 s, or the operation's `timeoutMs` if shorter). It is best effort: a 405 is accepted silently, any other failure (or the timeout) is only logged at debug level, and the operation's result never changes. Modern (`2026-07-28`) connections, legacy servers that issue no session id, and interrupted operations (an interrupt is never delayed; the session is left to expire) send no `DELETE`. `mcp.legacy.session` now also checks the session end (exactly one `DELETE` after the last POST, carrying the session id, answered 2xx or 405; none without a session), and every legacy conformance fixture with a session ends with the `DELETE` (answered 200, as the official server SDK answers it); the synthetic builders gain `legacySessionEndExchange`.

`@yolk-sdk/emulators/mcp` answers that `DELETE` on the synthetic legacy and Figma profiles: two new manifest rows (`DELETE <origin><path>#session-end`, twenty-one rows), the recorded 200 on a ready session, whose commit ends the session (later requests on it are refused), an `accept` of `*/*` tolerated (the fetch default), and the drill knob `sessionEndRejected` (the `DELETE` answered 404, failing only `mcp.legacy.session`). The fixture copies (`mcpEmulatorFixtures`, `mcpEmulatorServerPingFixtures`, `mcpEmulatorFigmaFixtures`) carry the new exchanges, and the conformance cross-checks now end exactly at the seed. `@yolk-sdk/connectors/figma/conformance` fixtures end each operation with the same `DELETE`.
