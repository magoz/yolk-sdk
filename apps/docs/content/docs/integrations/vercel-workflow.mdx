---
title: Deploy with Vercel Workflows
description: Orchestrate a durable agent run with host-owned model and tool steps.
---

Use `@yolk-sdk/vercel-workflows` when a run can outlive one request or pause for human input.

## Workflow wrapper

```ts
import { createHook } from 'workflow'
import { runVercelAgentWorkflow } from '@yolk-sdk/vercel-workflows'

export async function runAgentWorkflow(input: { request: unknown; context: unknown }) {
  'use workflow'

  return await runVercelAgentWorkflow({
    input,
    runModelStep,
    runToolBatchStep,
    closeStream,
    writeError,
    awaitInput: async awaitingInput => {
      using hook = createHook<unknown>({ token: awaitingInput.hookToken })
      return await hook
    }
  })
}
```

`runModelStep`, `runToolBatchStep`, `closeStream`, and `writeError` are app-owned `'use step'` functions.

## Durable stream rule

Write live events first, commit durable host state, then write terminal event. Let the workflow loop
or stream owner close once after terminal handling settles:

```txt
live events -> host durable commit -> terminal event -> workflow-owned close
```

Use `sequenceDurableAgentEvent` for deterministic event ids without IO,
`writeDurableAgentEvent` for id + NDJSON write, and `commitThenWriteTerminalEvent` for terminal
barriers.
