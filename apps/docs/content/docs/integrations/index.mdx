Yolk integrations are package-owned adapters you can plug into your host-owned auth, storage, policy, and UI.

## Model providers

| Provider                           | Use when                                                                  | Import                                                 |
| ---------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------ |
| OpenAI-compatible chat completions | You have an API key and want a generic OpenAI-compatible chat endpoint    | `@yolk-sdk/agent/providers/openai/provider`            |
| Vercel AI Gateway                  | You want Vercel routing across opaque `provider/model` ids                | `@yolk-sdk/agent/providers/vercel/ai-gateway-provider` |
| OpenAI Codex                       | You use Codex OAuth, Responses, or subscription-allowance snapshots       | `@yolk-sdk/agent/providers/openai/codex-provider`      |
| Anthropic Claude Code              | You use Claude OAuth, model requests, or subscription-allowance snapshots | `@yolk-sdk/agent/providers/anthropic/claude-provider`  |
| xAI Grok subscription              | You use a Grok consumer subscription through the xAI CLI proxy            | `@yolk-sdk/agent/providers/xai/grok-provider`          |
| Test provider                      | You need deterministic tests without network calls                        | `@yolk-sdk/agent/loop/testing`                         |

See [Model providers](./model-providers).

## Connector modules

| Connector        | Built-in actions                                                | Import                                 |
| ---------------- | --------------------------------------------------------------- | -------------------------------------- |
| Afloat           | remote MCP auth data                                            | `@yolk-sdk/connectors/afloat`          |
| Dropbox          | file metadata, search, and file management                      | `@yolk-sdk/connectors/dropbox`         |
| Generic email    | IMAP reads/drafts, POP3 reads, and SMTP submission              | `@yolk-sdk/connectors/email`           |
| Figma            | remote MCP auth data                                            | `@yolk-sdk/connectors/figma`           |
| Google           | Gmail and Calendar                                              | `@yolk-sdk/connectors/google`          |
| LinkedIn search  | Exa people search, Enrich Layer profile/email lookup            | `@yolk-sdk/connectors/linkedin-search` |
| Microsoft        | Outlook mail and OneDrive files through Microsoft Graph         | `@yolk-sdk/connectors/microsoft`       |
| Notion           | search, pages, blocks, databases, data sources, users, comments | `@yolk-sdk/connectors/notion`          |
| Cloudflare R2    | presigned upload URL                                            | `@yolk-sdk/connectors/r2-storage`      |
| Telegram         | send message, validate bot/chat                                 | `@yolk-sdk/connectors/telegram`        |
| Todoist          | projects, tasks, labels                                         | `@yolk-sdk/connectors/todoist`         |
| Custom connector | any Effect-native action set                                    | `@yolk-sdk/connectors`                 |

See [Connectors catalog](./connectors) and [Add connector tools](./connector-tool).

## Runtime/platform integrations

| Integration          | What ships                                                                                                                   | Import                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| MCP full-core client | MCP `2026-07-28` tools, resources, prompts, completions, MRTR, subscriptions, caching, OAuth helpers, and legacy negotiation | `@yolk-sdk/mcp/client`                         |
| MCP local stdio      | Node-only full-core stdio transport plus Yolk convenience helpers                                                            | `@yolk-sdk/mcp/client/node`                    |
| MCP full-core server | Dual-era HTTP, resources, prompts, completions, MRTR, and subscriptions                                                      | `@yolk-sdk/mcp/server`                         |
| MCP stdio server     | Node-only dual-era `serveStdio`                                                                                              | `@yolk-sdk/mcp/server/node`                    |
| MCP Yolk tool server | Expose Yolk tools through a minimal dual-era MCP server                                                                      | `@yolk-sdk/mcp/server`                         |
| Knowledge search     | document schemas, pinned context, ingestion/search contracts, lookup/manage tool helpers                                     | `@yolk-sdk/knowledge/*`                        |
| Sandbox execution    | core sandbox service, one destructive agent tool                                                                             | `@yolk-sdk/sandbox`, `@yolk-sdk/sandbox/agent` |
| Vercel Sandbox       | concrete sandbox provider layer                                                                                              | `@yolk-sdk/sandbox/vercel`                     |
| Vercel Workflows     | durable workflow loop contract                                                                                               | `@yolk-sdk/vercel-workflows`                   |

## Not included

Yolk does not ship database adapters, auth routes, token storage, vector database providers, product permissions, or UI components. Those stay host-owned so the SDK remains reusable.
