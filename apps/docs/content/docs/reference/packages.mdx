Package roots stay tiny. Import feature APIs from explicit subpaths.

## `@yolk-sdk/agent`

| Subpath | Purpose |
| --- | --- |
| `@yolk-sdk/agent/protocol` | wire messages, events, content, tools, usage, HITL |
| `@yolk-sdk/agent/loop` | stateless LLM/tool loop and services |
| `@yolk-sdk/agent/loop/testing` | faux provider and test tool executor |
| `@yolk-sdk/agent/runtime` | transcript and append-backed runtime orchestration |
| `@yolk-sdk/agent/client` | HTTP/NDJSON transport and client reducer helpers |
| `@yolk-sdk/agent/compaction` | context budget and window compaction helpers |
| `@yolk-sdk/agent/tools` | tool registry, `makeTool`, question/task modules |
| `@yolk-sdk/agent/react` | headless chat hook and projection helpers |
| `@yolk-sdk/agent/oauth` | provider-neutral access-token and broker contracts |
| `@yolk-sdk/agent/providers/openai/*` | OpenAI/Codex OAuth and provider factories |
| `@yolk-sdk/agent/providers/anthropic/*` | Anthropic/Claude OAuth and provider factories |
| `@yolk-sdk/agent/skillset` | portable skills and slash-command parsing |
| `@yolk-sdk/agent/voice` | voice tool-call bridge |

## Import rule

Prefer the narrowest subpath:

```ts
import { runRuntime } from '@yolk-sdk/agent/runtime'
import { makeTool } from '@yolk-sdk/agent/tools'
import { listRemoteMcpServerTools } from '@yolk-sdk/mcp/client'
```
