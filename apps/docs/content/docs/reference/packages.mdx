| Package                      | Use for                                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------- |
| `@yolk-sdk/agent`            | agent protocol, loop, runtime, client, React, tools, providers, OAuth, skillset, voice                  |
| `@yolk-sdk/mcp`              | MCP v2 full-core client/server, protocol schemas, and Yolk tool adapters                                |
| `@yolk-sdk/knowledge`        | knowledge documents, pinned context, search, ingestion, lookup/manage tools                             |
| `@yolk-sdk/connectors`       | external API actions, credentials, connector-to-agent-tool adapter                                      |
| `@yolk-sdk/sandbox`          | sandbox execution plane, Vercel adapter, agent sandbox tool                                             |
| `@yolk-sdk/vercel-workflows` | durable Workflow orchestration contracts                                                                |
| `@yolk-sdk/harness`          | run lifecycle: coordinator, store, inbox, and pluggable drivers (not the agent loop)                    |
| `@yolk-sdk/conformance`      | experimental: record, replay, and fault-inject HTTP wire fixtures; port fixtures; run conformance cases |
| `@yolk-sdk/emulators`        | experimental: service emulators and `HttpClient` routing to them for tests                              |

Package roots stay tiny. Import feature APIs from explicit subpaths.

## Import rule

Prefer the narrowest subpath:

```ts
import { runRuntime } from '@yolk-sdk/agent/runtime'
import { makeTool } from '@yolk-sdk/agent/tools'
import { listRemoteMcpServerTools } from '@yolk-sdk/mcp/client'
```
