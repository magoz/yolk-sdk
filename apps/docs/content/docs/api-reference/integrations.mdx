## MCP

| Subpath | Main exports |
| --- | --- |
| `@yolk-sdk/mcp/client` | `listMcpTools`, `listMcpServerTools`, `listRemoteMcpServerTools`, `listLocalMcpServerTools`, `callMcpServerTool`, `callRemoteMcpServerTool`, `callLocalMcpServerTool`, config and protocol adapters |
