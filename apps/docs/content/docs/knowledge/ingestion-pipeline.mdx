title: Ingest knowledge
description: Wire extraction, chunking, embeddings, summarization, and search storage into the ingestion pipeline.
---

`@yolk-sdk/knowledge` defines contracts. Your app provides concrete providers and stores.

## Install

```bash
pnpm add @yolk-sdk/knowledge@canary @yolk-sdk/agent@canary effect
```

## Pipeline shape

`ingestKnowledgeDocument` requires these Effect services:

| Service               | Host provides                                                              |
| --------------------- | -------------------------------------------------------------------------- |
| `SearchIndexStore`    | scope/document/chunk persistence and search                                |
| `KnowledgeExtractor`  | source loading and text extraction                                         |
| `KnowledgeChunker`    | text chunking; `DefaultKnowledgeChunkerLive` is available                  |
| `KnowledgeEmbedder`   | embedding provider                                                         |
| `KnowledgeSummarizer` | title/summary provider; use `NoopKnowledgeSummarizerLive` for simple hosts |

## Ingest a document

```ts
import { Effect, Layer } from 'effect'
import { DefaultKnowledgeChunkerLive } from '@yolk-sdk/knowledge/chunking'
import { NoopKnowledgeSummarizerLive } from '@yolk-sdk/knowledge/summarization'
import { ingestKnowledgeDocument } from '@yolk-sdk/knowledge/ingestion'

const KnowledgeLayer = Layer.mergeAll(
  HostSearchIndexStoreLayer,
  HostExtractorLayer,
  DefaultKnowledgeChunkerLive(),
  HostEmbedderLayer,
  NoopKnowledgeSummarizerLive
)

await Effect.runPromise(
  ingestKnowledgeDocument({
    scopeId: 'workspace-docs',
    documentId: 'doc_123',
    source: loadedSource,
    contentHash: 'sha256:...'
  }).pipe(Effect.provide(KnowledgeLayer))
)
```

`loadedSource` is host-owned source metadata/content from `@yolk-sdk/knowledge/extraction`.

## What ingestion does

1. Marks the document `processing`.
2. Extracts source text and metadata.
3. Chunks text using `maxTokens` or the default chunk size.
4. Embeds chunks and summarizes concurrently.
5. Replaces document chunks atomically.
6. Marks the document `ready` with title, summary, token count, and chunk count.

On failure, it best-effort marks the document `error` with a stage: `store`, `extract`, `chunk`, `embed`, or `summarize`.

## Search after ingestion

```ts
import { searchKnowledge } from '@yolk-sdk/knowledge/search'

const results = await Effect.runPromise(
  searchKnowledge({
    scope: { _tag: 'KnowledgeScope', id: 'workspace-docs' },
    query: 'How do approvals work?',
    mode: 'hybrid',
    limit: 5,
    contextChunks: 1
  }).pipe(Effect.provide(KnowledgeLayer))
)
```

Hybrid mode combines vector and text search with reciprocal-rank fusion.

## Add as an agent tool

```ts
import { Effect } from 'effect'
import { makeKnowledgeLookupTool } from '@yolk-sdk/knowledge/agent'

const lookupTool = makeKnowledgeLookupTool(HostKnowledgeLookupHandlers)
```

Resolve this tool with `@yolk-sdk/agent/tools` and pass it to the loop.

## Production notes

- Check permissions before choosing `scope`.
- Keep scope ids tenant-safe and host-owned.
- Store embedding model/dimensions in host-owned config.
- Re-ingest on content hash changes.
- Treat archived knowledge as retained but normally excluded from active search.
