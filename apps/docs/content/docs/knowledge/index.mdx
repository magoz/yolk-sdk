---
title: Knowledge package
description: Store simple durable knowledge, inject pinned context, search chunks, and expose lookup/manage tools.
---

Use `@yolk-sdk/knowledge` when your app needs durable agent-readable knowledge.

Knowledge is intentionally small:

```txt
KnowledgeDocument
  id
  slug
  title
  purpose
  origin
  content
  summary?
  errorMessage?
  reviewedAt?
  metadata?
  status: processing | ready | error
  availability: pinned | searchable | archived
  createdAt
  updatedAt
```

Install:

```bash
pnpm add @yolk-sdk/knowledge@canary @yolk-sdk/agent@canary effect
```

## Use pinned knowledge as context

```ts
import { buildKnowledgeContext } from '@yolk-sdk/knowledge'

const context = buildKnowledgeContext({
  documents,
  maxCharacters: 6000
})
```

Add the resulting text to your system prompt. Your app chooses which documents are pinned.

## Ingest a document into search

`ingestKnowledgeDocument` extracts, chunks, embeds, summarizes, replaces chunks, and updates document status.

```ts
import { ingestKnowledgeDocument } from '@yolk-sdk/knowledge/ingestion'

const program = ingestKnowledgeDocument({
  scopeId: 'workspace-docs',
  documentId: 'doc_123',
  source: loadedSource
})
```

Provide these layers from your app:

- `SearchIndexStore`
- `KnowledgeExtractor`
- `KnowledgeChunker`
- `KnowledgeEmbedder`
- `KnowledgeSummarizer`

## Search documents

```ts
import { Effect } from 'effect'
import { searchKnowledge } from '@yolk-sdk/knowledge/search'

const results = await Effect.runPromise(
  searchKnowledge({
    scope: { _tag: 'KnowledgeScope', id: 'workspace-docs' },
    query: 'How do agent tools work?',
    limit: 5,
    mode: 'hybrid',
    contextChunks: 1
  }).pipe(Effect.provide(HostKnowledgeSearchLayer))
)
```

The package defines the search contract. Your app implements the store and embedding provider.

## Expose tools

```ts
import { makeKnowledgeLookupTool, makeKnowledgeManageTool } from '@yolk-sdk/knowledge/agent'

const lookupTool = makeKnowledgeLookupTool(lookupHandlers)
const manageTool = makeKnowledgeManageTool(manageHandlers)
```

Use `knowledge_lookup` for search/get and `knowledge_manage` for explicit saves, pins, archives, renames, or deletes. Your app owns authorization and scope resolution.
