---
title: Installation
description: Install canary Yolk packages with matching lockstep versions.
---

Yolk packages currently publish on the `canary` channel and release in lockstep. Keep every `@yolk-sdk/*` dependency on the same version.

```bash
pnpm add @yolk-sdk/agent@canary effect@4.0.0
```

Use the SDK's matching Effect version (`4.0.0`) in host code. An unversioned `effect`
install can resolve a different API/type version; check this dependency when upgrading canaries.

Add sibling packages as needed:

```bash
pnpm add @yolk-sdk/mcp@canary @yolk-sdk/knowledge@canary @yolk-sdk/connectors@canary
pnpm add @yolk-sdk/sandbox@canary @yolk-sdk/vercel-workflows@canary workflow@^5.0.0-beta.42
pnpm add @yolk-sdk/harness@canary @yolk-sdk/codemode@canary @yolk-sdk/extractors@canary
# Only for XLSX extraction with @yolk-sdk/extractors: SheetJS from its CDN, not the npm `xlsx`.
pnpm add https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz
```

For tests, add the experimental conformance and emulator packages as dev dependencies:

```bash
pnpm add -D @yolk-sdk/conformance@canary @yolk-sdk/emulators@canary
```

`@yolk-sdk/harness` is available from `0.1.0-canary.77`. `@yolk-sdk/codemode`,
`@yolk-sdk/conformance`, and `@yolk-sdk/emulators` are available from `0.1.0-canary.96`; they are
unavailable in `0.1.0-canary.95` and earlier. `@yolk-sdk/extractors` is available from
`0.1.0-canary.98`. `@yolk-sdk/conformance` and `@yolk-sdk/emulators`
are experimental and meant for tests only; see [Test with emulators](./guides/testing-with-emulators).
Keep every package on the same lockstep version as the other public packages.

## Runtime expectations

| Requirement   | Notes                                                                                                                                                       |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Node          | Packages declare `>=22`; `@yolk-sdk/codemode` requires `>=22.19.0`                                                                                          |
| Module format | ESM only                                                                                                                                                    |
| Effect        | Runtime dependency during canary                                                                                                                            |
| React         | Optional peer only for `@yolk-sdk/agent/react`                                                                                                              |
| SheetJS       | Optional peer (`xlsx >=0.20.3`) only for XLSX extraction in `@yolk-sdk/extractors/node`; install the tarball from `cdn.sheetjs.com`                         |
| Workflow      | Required only by `@yolk-sdk/vercel-workflows` hosts; `workflow@^5.0.0-beta.42` (5.x region-pins runs — 4.x streams were `iad1`-only and burst cross-region) |

## Canary policy

Canary means APIs are useful but unstable. Expect breaking changes before `1.0.0`. Prefer explicit imports and small host adapters so package movement is easy to absorb.
